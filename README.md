# Student Life Simulator (kinda)

This is a demo project to see how different UI mechanics can be embedded to a gamification project.

This includes
- Basic fun screen space UI in the first scene.
- Basic fun world space UI in the second scene
- A pdf renderer in the third scene.
- A gamified Quiz in the fourth scene.
- A calisthenics sports program maker in the fifth scene


## How to Open

There are 3 ways to open this project:

### 1

You can open the project from your web browser using this [Link](https://play.unity.com/en/games/1a4df062-f34c-4ea6-92c2-12843f35dfa1/students-life-simulator) (Press ESC to stop the project when opened this way)

### 2

Locate "L_DatabaseBuild" file from this repo. [This](https://github.com/Oxygen-User/Learning_Database/tree/main/L_DatabaseBuild) is the file. Download the "L_DatabaseBuild" file and open the application ending with .exe on a windows computer. (Press ESC to close the project when opened this way)

### 3

Download this whole repository and view the project altogether on unity editor.

## How to Play/Use

change scenes by pressing next scene button on the screen.

-Explore the capability of the menus with the first 2 scenes and use WASD + right click 'n drag in the 2nd scene. 
-The pdf renderer doesn't work when the project is opened from web. Navigate the pdf using the "next" and "previous" buttons. The pdf reader is from [this](https://github.com/kdpkke/UnityPDFViewer) repo.
